### 2.3 删除神态（R3 相关）

连带清理 **30 处引用**，集中在四条链：

| 链路 | 处理 |
| --- | --- |
| 雷达/评分 | `RadarChartDTO` 去掉神态轴；`RadarComputationStrategy` 改为两参数 |

### 2.4 雷达权重与 null 语义（审查第 6 条）

按计划 §8 归一化：**简历 31.25% / 面试 68.75%**（原 25%/55% 去掉 20% 神态后重新归一）。

同时修掉审查发现的另一个问题：原实现 `defaultScore()` 把缺失分数写成 **0**，导致"没评"和"得 0 分"无法区分。现在：

- 单项缺失 → 该项为 `null`
- 只有一项 → 权重自动归一化，综合分等于该项分数（不被缺失项拉低）
- 两项都缺失 → 综合分为 `null`
- 报告维度输出时跳过 `null` 维度，不画成 0 分

`WeightedRadarComputationStrategyTest` 重写为 4 个用例覆盖上述语义。

### 2.5 接口与错误码

- 移除 `POST /interview/sessions/{id}/demeanor-evaluation`。
- `InterviewErrorCodeEnum` 去 7 个神态码；`AgentErrorCodeEnum` 去 4 个神态码。
- `BusinessAgentScene.INTERVIEW_DEMEANOR`、`BusinessAgentBindingProperties.interviewDemeanor`、`InterviewAiGuardStage.INTERVIEW_DEMEANOR`、守卫策略中的神态档位、限流的重接口判定全部移除。
- `InterviewAiInvoker` 删除仅神态使用的 4 参 `callAiSyncWithFile` 重载。

### 2.6 前端（仅停用入口，不重写）

- `InterviewPage` 的神态轮询 `enabled: false`（接口已删，否则每 5 秒 404）。
- 删除已无引用的 `services/agentService.ts`。
- `tsc --noEmit` 通过。
