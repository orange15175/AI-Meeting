## 4. 关键实现点

- **HTTP 层**：`api/http.ts` 用 axios 统一 `baseURL=/api`、自动带 `Authorization: Bearer`、解包后端 `Result{code,message,data}` 包装（`code==="0"` 或 `success` 视为成功）；HTTP 401/403 清 token 并跳登录。
- **鉴权**：登录写入 `localStorage`，路由守卫拦截未登录；`App.vue` 启动时用 `check-login` 静默恢复登录态。
- **普通聊天 SSE**：`api/chat.ts` 用 `fetch` 读 `text/event-stream`，按 `data:{json}` 帧增量解析 `content` / `reasoning_content`，支持 AbortController 停止生成。
- **面试答题**：`POST .../interview/answer-json`（JSON），每次提交生成 `requestId`（`crypto.randomUUID()`）用于幂等；收到 `finished=true` 后调用 `finish` 再跳报告。
- **构思板**：`TextSketchpad` 按 `sessionId` 存入 `localStorage`（`ai-meeting:sketchpad:{sessionId}`），支持「插入答案」。
- **设计 token**：背景 `#F6F8FB` / 表面 `#FFFFFF` / 正文 `#172033` / 次要 `#526079` / 主色 `#2458D3` / 边框 `#DCE3EE`，间距 4/8/12/16/24/32/48px，圆角 8/12/16px，与计划 §10.3 一致；桌面 224px 侧栏 + 64px 顶栏，移动端侧栏收窄为图标。

## 5. 契约对齐说明（不造假控件）

- **仅支持 PDF**：后端当前 `resumePdf` 只支持 PDF，前端 `accept` 也仅 `.pdf`，未假装支持 DOCX/图片（这些是净新增，待后端实现）。
- **无「跳过」按钮**：后端 `InterviewAnswerReqDTO.answerContent` 为 `@NotBlank`，当前没有 skip 端点，故只提供「提交回答 / 提前结束」，不做不可用的跳过控件。
- **无摄像头/语音/神态入口**：按 P1 边界，前端无媒体权限申请、无神态雷达，报告用分类条形图 + 逐题回顾替代旧雷达轴。
